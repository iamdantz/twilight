FONTLOG for Twilight Text and Twilight Code
===========================================

This file records the changes made to the Font Software and the people who made it, as the
SIL Open Font License recommends for Modified Versions.


Basic font information
----------------------

Twilight Text is the sans-serif typeface of Twilight, for interfaces, documentation and the
web. Twilight Code is its monospaced typeface, for code editors and terminals.

Both are Modified Versions of fonts released under the SIL Open Font License 1.1, with no
Reserved Font Name:

- Twilight Text derives from Atkinson Hyperlegible Next 2.001.
  https://github.com/googlefonts/atkinson-hyperlegible-next
- Twilight Code derives from Atkinson Hyperlegible Mono 2.001.
  https://github.com/googlefonts/atkinson-hyperlegible-next-mono

The upstream design sources and license files are kept unmodified in fonts/upstream/, pinned
to one commit and verified by SHA-256 (fonts/upstream.json). Every change below is applied by
fonts/scripts/build.py when the fonts are built; nothing is edited by hand.

Twilight Text and Twilight Code are licensed under the SIL Open Font License 1.1
(fonts/OFL.txt). The rest of the Twilight repository is licensed under the MIT License.


ChangeLog
---------

Twilight Text 1.002 and Twilight Code 1.003 (Twilight 1.17.0)
- Added, in both families: geometric shapes (U+25A0–25A1, 25AA–25AB, 25B2–25B9, 25BC–25C3,
  25C6–25C7, 25CB, 25CF, 25E6), U+2205–2206 and U+27E8–27E9, computed by
  fonts/scripts/symbols.py from each master's measures; U+00B5, 2016, 2032–2033, 2074,
  2081–2084 and 2153–2154, assembled from existing outlines, moved and not redrawn (⁴ scaled
  by under 3 %). Twilight Text only: U+2116.
- Added to Twilight Code: braille patterns U+2800–28FF (fonts/scripts/braille.py, dots from the
  period) and the rounded Powerline separators U+E0B4–E0B7.
- fonts/scripts/symbolcheck.py verifies them at every named instance. No other change:
  fonts/scripts/check.py finds no difference from the upstream fonts beyond the added
  characters, declared in fonts/changes.json.

Twilight Text 1.001 and Twilight Code 1.002 (Twilight 1.16.0)
- Added arrows: U+2190–2199, U+21A9–21AA, U+21B5 and U+21D0–21D3 in both families, and
  U+21D4–21D5 in Twilight Text only. They are computed by fonts/scripts/arrows.py from each
  master's plus sign (stroke, axis, length, side bearings), equal sign (line spacing) and
  italic angle; fonts/scripts/arrowcheck.py verifies them at every named instance.
- No other change: fonts/scripts/check.py finds no difference from the upstream fonts beyond
  the added characters, declared in fonts/changes.json.

Twilight Code 1.001 (Twilight 1.15.0)
- Added the box drawing characters (U+2500–257F), the block elements (U+2580–259F) and the
  Powerline separators (U+E0B0–E0B3), computed by fonts/scripts/boxdraw.py from each master's
  advance width, typographic line box and hyphen thickness. Lines reach the cell edges;
  fonts/scripts/boxcheck.py verifies the joins at every named instance.
- No other change: fonts/scripts/check.py finds no difference from the upstream fonts beyond
  the added characters, declared in fonts/changes.json.

Twilight Text and Twilight Code 1.000 (Twilight 1.14.0)
- Family names changed to Twilight Text and Twilight Code; file names to TwilightText and
  TwilightCode.
- Copyright notice extended with the Twilight copyright line; manufacturer and manufacturer
  URL set to Twilight; a description crediting the upstream family and its designers added.
- Font version set to 1.000.
- No outline, spacing, kerning or feature changes. fonts/scripts/check.py compares every
  named instance with the upstream fonts at the pinned commit: same glyphs, character map,
  axes, metrics, advance widths and shaping; outlines within 0.5 font units, the tolerance
  of variable-font delta optimization.
